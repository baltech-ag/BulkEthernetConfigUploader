# Certificates

`PKI_AUTH_BALTECH_FOR_KOFAX_TRANSPORT.zip` is the PKI transport certificate package of this
installation (PkiAuthZip layout: `host_chain/`, `reader_chain/`, `keypair.key`,
`settings.cfg`). The tool loads the single `*.zip` in this folder by default; `--cert <path>`
on the command line or "Change..." in the window selects another package.
